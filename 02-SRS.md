Functional Requirements

FR1: The system shall allow only HR to edit leave balances.
FR2: The system shall display the employee's current leave balance at any time upon request.
FR3: The system shall notify the employee if their leave balance is insufficient, and shall deduct the leave as unpaid if the employee chooses to proceed, while notifying the manager.
FR4: The system shall automatically route the leave request to the Delegate Approver when the manager's status is On Leave.

Request Status Values

Pending Manager Approval
Pending HR Approval
Approved
Declined

Non-Functional Requirements

NFR1: The system shall restrict employees from viewing other employees' leave data, except HR.
NFR2: The system shall allow managers to view leave data only for their own team.

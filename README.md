# Employee-Leave-Management-BA

Business Analyst self-project - Employee Leave Management System

This project is a system that makes it easier for employees and managers 
to submit and approve leave requests. It was built to address a real 
problem in companies where leave requests caused delays and had to go 
through multiple people and communication channels. It covers the full 
process: submitting a request, manager and HR approval, and leave 
balance tracking.

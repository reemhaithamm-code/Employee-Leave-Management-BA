# As-Is Process (Current State)

## Scenario A: Manager Available
1. Employee sends leave request to manager via WhatsApp
2. Manager checks if it will disrupt work
3. If approved, employee informs HR
4. HR checks leave balance
5. HR responds with result

## Scenario B: Manager Unavailable
1. No formal approver assigned
2. Employee contacts HR or senior team member informally

## Key Problems Identified
1. Requests go through different channels like WhatsApp and phone calls, with no single place to track them
2. No formal delegation/escalation process when manager is unavailable
3. No self service visibility into leave balance employee must ask HR every time
